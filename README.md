# Klyvo POD

Klyvo is a Next.js + Bun streetwear/POD storefront, built from the functional architecture of StockMark while using the Klyvo visual system and customer experience.

## Stack

- Next.js App Router
- React + TypeScript
- Bun
- Tailwind CSS
- Clerk-ready authentication
- libSQL/Turso-ready commerce data layer
- CJdropshipping-ready supplier integration

## Development

```bash
bun install
bun run dev
```

Copy `.env.example` to `.env.local` and configure the integrations you want to enable.
